# NET-INFO
Site institucional responsivo e estático. Abra index.html ou execute `npm start` e visite http://localhost:4173.

Planos e contato em index.html, aparência em style.css, interações em script.js. Vídeo fornecido pelo proprietário em assets/conexao.mp4. Preços, endereço, telefone e CNPJ conforme informações fornecidas. A contratação e consulta de cobertura são feitas diretamente pelo WhatsApp; não há coleta ou armazenamento de dados no site.

Publicação automática pelo GitHub Actions no push para main. Para adicionar o domínio depois: Settings → Pages → Custom domain, configurar os registros DNS e habilitar HTTPS. Nenhum domínio personalizado foi configurado nesta versão.
